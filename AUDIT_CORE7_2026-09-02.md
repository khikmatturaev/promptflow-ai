## CORE 7 implementation

### Production Code Intelligence

New `src/lib/codeIntelligence.ts` reviews generated artifacts for:

- manifest integrity
- entrypoint availability
- source presence
- unfinished implementation markers
- possible hardcoded credentials
- environment contract
- generated tests
- architecture contract documentation

It returns a bounded score, findings, strengths, and next actions. The score is explicitly heuristic and is not a security certification.

### Real Build Workspace

New `src/lib/projectWorkspace.ts` and `src/types/workspace.ts` provide:

- inspectable project file model
- local workspace manifest
- artifact browser integration
- local ZIP export
- no server upload

The ZIP writer is dependency-free and uses the standard ZIP stored-file format. It includes generated artifacts plus `promptflow/workspace.json`.

### Production artifact review

New `src/types/codeIntelligence.ts` exposes typed review contracts.

### Final Hackathon Demo

New `src/lib/finalDemo.ts` orchestrates:

Architecture → Intelligence → Load Simulation → Digital Twin → Implementation → Code Generation → Code Review → Build Workspace → Architecture DNA.

The orchestration is non-destructive to the live architecture.

### Agent OS

CORE 7 adds:

- `export_project_artifacts`
- `run_final_hackathon_demo`
